## 余额模型

核心恒等式（来自表注释）：

**总余额 = 可用余额 + 冻结余额 + 在途金额**

四个余额的含义：

| 字段              | 含义                   | 什么时候变               |
| ----------------- | ---------------------- | ------------------------ |
| total_balance     | 总余额，上面四项之和   | 任何真实资金进出         |
| available_balance | 可用余额，可花可提     | 充值到账、解冻、结算完成 |
| frozen_balance    | 冻结余额，已被业务占用 | 冻结、履约扣减           |
| pending_amount    | 在途金额，结算中未到账 | 结算发起、结算完成       |

常见资金动作的余额变化（示例口径，以业务实现为准）：

| 动作                   | 可用 | 冻结 | 在途 | 总额 |
| ---------------------- | ---- | ---- | ---- | ---- |
| 在途入账（结算发起）   | 不变 | 不变 | +X   | +X   |
| 在途转可用（结算完成） | +X   | 不变 | -X   | 不变 |
| 冻结                   | -X   | +X   | 不变 | 不变 |
| 解冻                   | +X   | -X   | 不变 | 不变 |
| 冻结扣款（履约支付）   | 不变 | -X   | 不变 | -X   |
| 可用扣款（手续费等）   | -X   | 不变 | 不变 | -X   |

规律：只在余额桶之间搬家时，总额不变；真实资金进出时，总额才变。

## 资金流水表 fund_transaction

| 列             | 类型           | 约束 / 默认         | 说明                                 |
| -------------- | -------------- | ------------------- | ------------------------------------ |
| transaction_id | uuid           | 主键，默认 uuidv7() | 流水ID                               |
| transaction_no | text           | 唯一，非空          | 流水业务编号（全局唯一）             |
| account_id     | uuid           | 非空                | 账户ID，逻辑关联账户表               |
| account_no     | text           | 非空                | 账户编号（冗余，免联表查询）         |
| biz_type       | text           | 非空                | 业务类型（充值、结算、退款等）       |
| biz_no         | text           | 非空                | 业务单号                             |
| balance_type   | text           | 非空                | 余额类型：AVAILABLE、FROZEN、PENDING |
| direction      | text           | 非空                | 收支方向：IN 收、OUT 支              |
| balance_before | numeric(20, 6) | 非空                | 交易前余额（该余额类型下）           |
| amount         | numeric(20, 6) | 非空                | 发生金额                             |
| balance_after  | numeric(20, 6) | 非空                | 交易后余额（该余额类型下）           |
| currency       | text           | 非空                | 币种（ISO 4217）                     |
| settle_status  | text           | 非空                | 结算状态                             |
| settled_at     | timestamptz    | 可空                | 结算时间                             |
| remark         | text           | 可空                | 备注                                 |
| created_at     | timestamptz    | 默认 now()          | 创建时间                             |
| updated_at     | timestamptz    | 非空                | 更新时间                             |



**记账链**：每条流水只动一个余额桶。`balance_type` 指明动哪个桶，`direction` 指明方向（IN 收、OUT 支），`balance_before → amount → balance_after` 记录该桶的变化前后。前后余额首尾相接，任何时点的余额都能从流水重放出来。

**双桶记账**：余额桶之间的转移记两条流水，一桶出一桶进。以商户资金冻结 100 元为例（可用转冻结）：

| 流水 | balance_type | direction | amount | 效果           |
| ---- | ------------ | --------- | ------ | -------------- |
| A    | AVAILABLE    | OUT       | 100.00 | 可用余额减 100 |
| B    | FROZEN       | IN        | 100.00 | 冻结余额加 100 |

两条流水同账户、同业务、同一事务落库。财务对账时闭环：可用少 100，冻结多 100，总余额不变。每个桶各自的前后余额首尾相接，可用桶与冻结桶都能独立重放出余额。

**幂等**：`(biz_type, biz_no, account_id)` 唯一。同一业务单对同一账户最多记一条流水。重试、消息重投会被唯一索引直接拦下。双桶动作会产生两条流水；两条流水要各用一个业务单号。

**结算跟踪**：`settle_status` 与 `settled_at` 记录在途资金的结算进度。



## 记账示例

商户人民币账户，初始：可用 1000，冻结 0，在途 0，总额 1000。

| 步骤 | 动作             | 流水（余额类型 · 方向 · 金额 · 前→后）                       | 可用 | 冻结 | 在途 | 总额 |
| ---- | ---------------- | ------------------------------------------------------------ | ---- | ---- | ---- | ---- |
| 1    | 结算入账（在途） | PENDING · IN · 200 · 0→200                                   | 1000 | 0    | 200  | 1200 |
| 2    | 冻结 150（两桶） | AVAILABLE · OUT · 150 · 1000→850；FROZEN · IN · 150 · 0→150  | 850  | 150  | 200  | 1200 |
| 3    | 结算完成（两桶） | PENDING · OUT · 200 · 200→0；AVAILABLE · IN · 200 · 850→1050 | 1050 | 150  | 0    | 1200 |
| 4    | 履约扣款         | FROZEN · OUT · 150 · 150→0                                   | 1050 | 0    | 0    | 1050 |

每一步恒等式都成立。注意两点：

- 步骤 2、3 就是上文的双桶记账：桶间转移，每个桶一条流水，两条流水同事务落库。因为幂等键不含 `balance_type`，两条流水要用不同的业务单号（如加序号后缀），否则第二条会被唯一索引拒绝。
- 桶间搬家（步骤 2、3）总额不变；真实资金进出（步骤 1、4）总额才变。
